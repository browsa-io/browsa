[Browsa](https://browsa.io) runs cloud browsers for AI agents. Its browser, Phantom, runs in the cloud and is driven through an API: describe a task in plain language and a browser agent does it, or fetch, extract from or screenshot a single page in one call.

This guide provides a quick overview for getting started with the Browsa [tools](/oss/langchain/tools). For a detailed listing of all Browsa features, parameters, and configurations, head to the [Browsa API reference](https://browsa.io/docs).

### Features

| Tool | What it does | Credits |
| :--- | :--- | :--- |
| `BrowsaTaskTool` | Runs a plain-language task: an agent clicks, types and reads pages until it has the answer | browser + 1 + 1 per 5 steps, + 5 on a hosted tier |
| `BrowsaScrapeTool` | Returns one page as Markdown, HTML, text or links | 1 per page |
| `BrowsaExtractTool` | Returns structured data from one page | 1 per page |
| `BrowsaScreenshotTool` | Returns a PNG of one page | 1 per page |

A cloud browser costs 1 credit per started 12 minutes it runs. Prices are from the [Browsa pricing page](https://browsa.io/pricing). `BrowsaToolkit` returns all four tools, and `BrowsaLoader` loads scraped or crawled pages as `Document` objects.

## Setup

To access the Browsa tools, you'll need to create a Browsa account, get an API key, and install the `langchain-browsa` integration package. New accounts get 100 free credits after email verification.

### Credentials

Create an API key at [app.browsa.io](https://app.browsa.io/dashboard/keys). Keys start with `agt_live_`.

```python Set API key icon="key"
import getpass
import os

if "BROWSA_API_KEY" not in os.environ:
    os.environ["BROWSA_API_KEY"] = getpass.getpass("Enter your Browsa API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The Browsa tools live in the `langchain-browsa` package:

<CodeGroup>

</CodeGroup>

## Instantiation

```python Initialize tool instance icon="robot"
from langchain_browsa import BrowsaTaskTool

tool = BrowsaTaskTool()
```

By default the task runs on Browsa's hosted model tier `browsa`, so no LLM key is needed. Use `llm="browsa-fast"` or `llm="browsa-smart"` for the other hosted tiers, or a provider model with your own key:

```python Use your own model key icon="key"
tool = BrowsaTaskTool(
    llm="anthropic:claude-sonnet-5-5",
    llm_api_key=os.environ["ANTHROPIC_API_KEY"],
)
```

Other options include `output_schema` (a JSON Schema for the answer), `max_steps`, `max_credits` (a spending cap for one task), `allowed_domains` and `reasoning`.

## Invocation

### Directly

The tool takes a `task` (required) and an optional `initial_url`:

```python Call tool icon="rocket"
result = tool.invoke({"task": "Open example.com and return the text of the H1 heading."})
print(result["outcome"], result["final_result"])
```

The result has `status` (the run ended), `outcome` (how it ended), `succeeded`, `final_result`, `structured_output` (with `output_schema`), `credits_charged` and `live_url`. Read `outcome`, not only `status`: a run with `status` `completed` and `outcome` `failed` means the agent finished but could not do the task.

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"task": "Open example.com and return the text of the H1 heading."},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### Within an agent

We can use our tool in an agent. For this we will need a model with tool-calling capabilities.

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent
from langchain_browsa import BrowsaToolkit

tools = BrowsaToolkit().get_tools()
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=tools,
)

# Run the agent
agent.invoke(
    {"messages": [{"role": "user", "content": "What is the top story on news.ycombinator.com right now?"}]}
)
```

## Structured output

Pass a JSON Schema to get the answer as an object:

```python Structured output icon="brackets-curly"
tool = BrowsaTaskTool(
    output_schema={
        "type": "object",
        "properties": {"title": {"type": "string"}, "points": {"type": "integer"}},
        "required": ["title", "points"],
    },
    max_credits=20,
)
result = tool.invoke({"task": "Return the title and points of the top story on news.ycombinator.com"})
print(result["structured_output"])
```

## One-call page tools

```python Scrape, extract and screenshot icon="globe"
from langchain_browsa import BrowsaExtractTool, BrowsaScrapeTool, BrowsaScreenshotTool

page = BrowsaScrapeTool().invoke({"url": "https://example.com"})
print(page["markdown"])

data = BrowsaExtractTool(llm_api_key=os.environ["ANTHROPIC_API_KEY"]).invoke(
    {"url": "https://example.com", "prompt": "Return the page heading."}
)
print(data["data"])

shot = BrowsaScreenshotTool()
msg = shot.invoke({"name": shot.name, "type": "tool_call", "id": "1", "args": {"url": "https://example.com"}})
png_base64 = msg.artifact["screenshot_png_b64"]
```

`BrowsaExtractTool` runs the extraction with an Anthropic key (`llm_api_key`, or a saved key with `llm_key_id`). Without one it returns the page text and the schema for your own model.

## Loading pages as documents

```python Document loader icon="file-lines"
from langchain_browsa import BrowsaLoader

docs = BrowsaLoader("https://example.com").load()
crawled = BrowsaLoader("https://docs.example.com", mode="crawl", max_pages=10).load()
```
